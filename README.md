# Real-Time Chat and Calling

Pre-implementation repository for a one-to-one real-time chat and audio/video calling web application.

## Status

No implementation, security, capacity, or accessibility claim is made yet. The application scaffold, tests, and CI will land in later phases.

## Repository scope

This public repository contains source code, tests, CI configuration, `.env.example`, and this README. Product requirements and delivery planning are maintained privately and are not part of this repository.

## Branching

`main` is the protected default branch. Changes land through pull requests; direct pushes, force pushes, and branch deletion are blocked.

## Local development

Setup instructions and `.env.example` will be added with the application scaffold. Do not commit credentials, production data, private message content, database dumps, or backups.

## Security

Do not open public issues containing secrets, private message content, or personal data.
